# NeoBot — بوت ديسكورد + لوحة تحكم

بوت (discord.js) ولوحة تحكم ويب (Express) مربوطين ببعض. كل الإعدادات بتتعدل من الموقع وبتنطبق فوراً على البوت بدون إعادة تشغيل.

## الأنظمة

| النظام | الشرح |
|---|---|
| التذاكر | لوحة إيمبد + قائمة منسدلة، قناة خاصة، استلام، إغلاق، حفظ المحادثة بالموقع وإرسال نسخة للوق وللعضو |
| الترحيب والرتب | رسالة ترحيب (نص أو إيمبد + بانر)، رسالة خاصة، رسالة مغادرة، رتب تلقائية للأعضاء والبوتات |
| اللوقات | حذف/تعديل رسائل، دخول/خروج، رتب ولقب وتايم أوت، حظر، قنوات، رتب، صوت |
| الحماية | سبام، روابط (مع دومينات مسموحة)، روابط دعوات، منشن جماعي، Anti-Raid (موجة دخول + عمر الحساب) |
| هوية البوت | أي سيرفر بيضيف البوت بيقدر يغيّر اسمه وصورته بهالسيرفر فقط، من أمر `/branding` أو من صفحة "هوية البوت" بالموقع |
| القوانين | قائمة قوانين (حتى 25) بإيمبد أو نص عادي، تنشرها بقناة بزر **حفظ ونشر** أو أمر `/rules`، والنشر مرة ثانية بيحدّث نفس الرسائل |
| الإدارة | صاحب السيرفر بيضيف ناس بالآيدي ويحدد لكل واحد أي صفحات بلوحة التحكم بيشوفها (بيدخلوا بحساب ديسكورد تبعهم) |
| اللغة | عربي أو English: لغة البوت لكل سيرفر (صفحة هوية البوت) + زر تبديل لغة الواجهة بالموقع |
| المودريشن | `/ban` `/unban` `/kick` `/timeout` `/untimeout` `/warn` `/warnings` `/clearwarns` `/purge` + سجل عقوبات + تايم أوت تلقائي بعد X تحذيرات |

الموقع: واجهة ثلاثية الأبعاد (CSS فقط)، تسجيل دخول بديسكورد، اختيار السيرفر بكروت، إحصائيات، سجل التذاكر مع بحث وعرض المحادثات، وصفحة لكل نظام.

## 1) تجهيز البوت على ديسكورد

افتح https://discord.com/developers/applications واعمل Application جديد (سمّيه NeoBot وحط اللوقو):

1. **General Information:** انسخ `Application ID` ← هذا `CLIENT_ID`.
2. **Bot:**
   - اضغط Reset Token وانسخه ← هذا `DISCORD_TOKEN` (لا تعطيه لأي حدا).
   - فعّل **Server Members Intent** و **Message Content Intent**.
3. **OAuth2:**
   - انسخ `Client Secret` ← هذا `CLIENT_SECRET`.
   - من **Redirects** ضيف: `http://localhost:3000/auth/callback`
     (على استضافة: `https://موقعك/auth/callback`).

## 2) التشغيل (Node.js 18.17 أو أحدث)

افتح الـ cmd **داخل مجلد المشروع** (اللي فيه `package.json`):

```
copy env.example .env
notepad .env
npm install
npm start
```

عبّي القيم بملف `.env`:

| المتغير | القيمة |
|---|---|
| `DISCORD_TOKEN` | توكن البوت |
| `CLIENT_ID` | Application ID |
| `CLIENT_SECRET` | Client Secret |
| `BASE_URL` | `http://localhost:3000` (أو رابط موقعك) |
| `SESSION_SECRET` | أي نص عشوائي طويل |

لما يشتغل رح تشوف: `[bot] شغال كـ ...` و `[web] لوحة التحكم: ...`

## 3) الاستخدام

1. افتح `http://localhost:3000` وسجّل دخول بديسكورد. كل شخص بيشوف **فقط السيرفرات اللي عنده فيها Administrator أو Manage Server** والبوت موجود فيها (بيتحقق من ديسكورد بكل طلب).
2. اضغط **إضافة البوت لسيرفر** (بيطلب Administrator لأن الحماية والمودريشن بتحتاج صلاحيات كثيرة) وبعدها **تحديث**.
3. اختر السيرفر. صفحة **هوية البوت** لتغيير الاسم واللوقو، وباقي الصفحات لكل نظام.
4. صفحة **التذاكر:** اختر الكاتيجوري ورتب الإدارة وقناة اللوج. كل نوع تذكرة إله رتب إدارة خاصة فيه (فاضي = الرتب العامة)، والتذكرة بيشوفها بس صاحبها + هالرتب + الأدمنز.
    بعدها اختر قناة واضغط **حفظ وإرسال اللوحة**.

أي سيرفر بيضيف البوت بيوصله رسالة ترحيب فيها الخطوات، وصاحب السيرفر بيقدر يغيّر اسم وصورة البوت عنده بأمر `/branding` من ديسكورد مباشرة.

## ملاحظات مهمة

- **ترتيب الرتب:** لازم رتبة البوت تكون أعلى من الرتب اللي بيعطيها (رتب تلقائية) ومن الأعضاء اللي بيعاقبهم.
- **اللوحات القديمة:** تغيير شكل اللوحة ما بيغيّر اللوحات المرسلة قبل. احذفها وأرسل جديدة.
- **البيانات:** كلها بملف `data/db.json`. خذ منه نسخة احتياطية دورياً. هيك التخزين مناسب لعدد سيرفرات صغير/متوسط.
- **الجلسات:** مخزنة بالذاكرة، فلما تعيد تشغيل البرنامج لازم تسجل دخول من جديد بالموقع (البوت نفسه ما بيتأثر).
- **على استضافة:** حط `BASE_URL` برابط https، وضيف نفس رابط الرجوع بالـ Redirects، وشغّل خلف HTTPS. لما `BASE_URL` مش localhost الموقع بيفتح للخارج (تسجيل الدخول بيحميه).
- **الإدارة (الموظفين):** بتعطيهم صلاحية على صفحات الموقع فقط؛ مين بيشوف التذاكر بديسكورد بتحدده رتب الإدارة بصفحة التذاكر. صفحتا الإدارة واللغة لصاحب السيرفر/الأدمن فقط.
- **لوحة المالك 👑:** حط آيدي حسابك بـ `OWNER_ID` داخل `.env` (أو بيعتبرك صاحب البوت تلقائياً إذا إنت مالك التطبيق بديسكورد). بتظهر لك بالشريط العلوي زر "لوحة المالك": كل السيرفرات اللي فيها البوت، إخراج البوت من أي سيرفر، وإضافة "إدارة البوت" بالآيدي (بيشوفوا السيرفرات بس، والإضافة والإخراج لك إنت). غيرك ما بيشوفها.
- **هوية البوت:** تغيير الاسم/الصورة بيطبّق على السيرفر نفسه فقط، وديسكورد بيحط حد يومي على تغيير الصورة.
- **الأمان:** ملف `.env` فيه أسرار، لا ترفعه على GitHub ولا ترسله لحدا. إذا انكشف التوكن اعمل له Reset فوراً.
- **حفظ محادثة التذكرة:** بتنحفظ بالموقع لحظة الإغلاق (حتى 5000 رسالة).

## تخزين دائم مجاني بـ Supabase (للاستضافات اللي بتمسح الملفات مثل Render)

1. سجّل بـ supabase.com وأنشئ مشروع جديد (Free).
2. من **SQL Editor** شغّل:
   ```sql
   create table if not exists kv (id text primary key, value jsonb not null);
   alter table kv enable row level security;
   ```
   (تفعيل RLS بدون سياسات بيمنع أي وصول عام للجدول، والبوت بيدخل بالمفتاح السري.)
3. من **Project Settings → API** انسخ:
   - **Project URL** ← `SUPABASE_URL`
   - **service_role key** (السري، مش anon) ← `SUPABASE_KEY`
4. ضيفهم بـ `.env` أو بـ Environment على الاستضافة. أول تشغيل بيرفع بياناتك الحالية، وبعدها كل التغييرات بتنحفظ هناك (بتأخير 3 ثواني تقريباً).

مهم: مفتاح `service_role` سري جداً، لا ترفعه على GitHub ولا تحطه بالواجهة.
